# Сборщик корпоративных переписок в Telegram (`tg_aggregator`)

Модульный Telegram-бот на Python (`aiogram 3.x`), предназначенный для автоматического сбора корпоративных переписок (текст, медиа, документы, реакции) и их надежного сохранения в реляционную базу данных PostgreSQL. Собранные данные используются для анализа качества коммуникаций, поиска информации и аналитики.

## 🛠 Стек технологий

* **Язык программирования:** Python 3.10+

* **Фреймворк для Telegram API:** aiogram 3.x

* **ORM / Работа с БД:** SQLAlchemy

* **База данных:** PostgreSQL

* **Управление окружением:** python-dotenv (`load_dotenv()`)

## 📁 Архитектура и структура проекта

Проект реализован по модульному принципу:

```
tg_aggregator/
├── database/            # Модуль работы с БД (модели SQLAlchemy, сессии)
│   ├── models.py        # Модели пользователей, чатов и истории сообщений
│   └── session.py       # Подключение и инициализация асинхронных сессий PostgreSQL
├── handlers/            # Модули обработчиков Telegram
│   ├── collector.py     # Модуль сбора и сохранения входящих сообщений
│   └── admin.py         # Модуль интерфейса администратора (выгрузка данных)
├── .env                 # Переменные окружения и секреты (не отслеживается в Git)
├── .gitignore           # Исключения для Git
├── main.py              # Общий модуль (точка входа, точка сборки бота)
├── README.md            # Полная документация проекта
└── requirements.txt     # Перечень всех зависимостей

```

## ⚙️ Инструкция по установке и запуску

### 1. Клонирование репозитория

```
git clone https://github.com/magziiiim/pr.octagon
cd tg_aggregator

```

### 2. Создание и активация виртуального окружения

```
python3 -m venv venv
source venv/bin/activate

```

### 3. Установка зависимостей

```
pip install -r requirements.txt

```

### 4. Настройка конфигурации (`.env`)

Создайте файл `.env` в корневой директории проекта и заполните его необходимыми переменными окружения (см. подраздел ниже).

### 5. Запуск бота

```
python3 main.py

```

## 🔐 Подробное описание файла `.env`

Все чувствительные и «секретные» данные передаются исключительно через переменные окружения в файле `.env` и загружаются в программу с помощью функции `load_dotenv()` из библиотеки `python-dotenv`.

### Перечень и описание всех полей `.env`:

1. **`BOT_TOKEN`**: Уникальный токен аутентификации Telegram-бота, полученный через официального бота [@BotFather](https://t.me/BotFather). Используется для авторизации запросов к Telegram Bot API.

2. **`DB_URL`**: Полная URL-строка подключения к базе данных PostgreSQL для ORM SQLAlchemy. Содержит указание драйвера (например, `postgresql+psycopg2`), логин, пароль, хост, порт и имя базы данных.

3. **`ADMIN_IDS`**: Telegram ID

### Пример готового файла `.env`:

```
# Токен бота из @BotFather
BOT_TOKEN=9009419264:AAEb...

# URL-строка подключения к базе данных PostgreSQL для SQLAlchemy
DB_URL=postgresql+psycopg2://postgres:my_secure_password@localhost:5432/tg_aggregator

# Список ID администраторов Telegram (через запятую)
ADMIN_IDS=tg_id

```

> **Важно:** Файл `.env` обязательно внесен в `.gitignore` и не попадает в публичный репозиторий в целях безопасности.
